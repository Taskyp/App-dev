# The Lord of the Rings

## Overview
**The Lord of the Rings** is a *fantasy film trilogy* directed by **Peter Jackson**, based on the novels by J.R.R. Tolkien.

## Films
1. The Fellowship of the Ring (2001)
2. The Two Towers (2002)
3. The Return of the King (2003)

## Main Characters
- Frodo Baggins
- Samwise Gamgee
- Gandalf
  - A wizard and guide of the Fellowship
- Aragorn
